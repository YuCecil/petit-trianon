# 插圖提示詞模板（18 世紀粉彩速寫風）

> 提示詞由主 session 寫好，貼到 Gemini（透過 Claude in Chrome）。操作的 agent 必須原封不動照貼。
> 同一批圖盡量在同一個 Gemini 對話裡生成，風格比較一致；每張都要求「構圖不同」。

```
請生成一張橫式 3:2 的插圖。
畫風：18 世紀法國粉彩速寫，像洛可可時期畫家的習作。奶油色紙底（#FBF7F0），
柔和的粉彩與淡水彩筆觸，線條輕、留白多，看得到紙的紋理。
配色只用：國王藍 #2E4F98、天藍 #8CC2DD、蘋果綠 #A9CB8C、龐巴度粉 #EBA3AE、
黃水仙 #F0D46E、紫羅蘭 #BFA6D3，加極少量的金色 #B08D4E。
構圖：【和本站其他插圖不同，例如近景靜物／室內／遠景／俯視】
場景：【1770–1793 年，在哪裡、有什麼物件、誰在做什麼；要能從故事頁的出處找到根據】
人物只能是遠景、背影、側影或剪影，不要畫清楚的臉，不要像真實人物的肖像畫。
畫面中不要出現任何文字、字母、數字、簽名或浮水印。
```

## 修圖提示詞（在同一個對話裡接著說）

- 局部修改：「保持畫風和構圖，只把【哪裡】改成【怎樣】。」
- 去背（吉祥物）：「保持造型，改成純白背景、沒有陰影，方便去背。」
- 統一畫風：附上一張既有插圖，說「照這張的筆觸和配色重畫」。

## 吉祥物（王后的小狗）

- 造型定案後，把造型描述寫進 `rules/site.md` 8.3，之後每次都把整段造型描述貼進提示詞，不要只寫「同一隻狗」。

## 規則

- 場景對應故事頁裡**有出處**的內容，不畫史料沒有的事。
- 存檔：原圖 `raw/images/<故事id>.png`；網站用 `docs/assets/img/<故事id>.jpg`，寬 1000px、品質 70（`sips -Z 1000 -s format jpeg -s formatOptions 70 原圖 --out 目標`）。
- frontmatter 加 `image: <故事id>.jpg` 與 `imageAlt: 粉彩畫風插畫：……`。
- 內文插圖：`docs/assets/img/<故事id>-2.jpg`，在段落後另起一行寫 `{{img:<故事id>-2.jpg|一句話說明畫面}}`。
- Gemini 同一個對話生到上限會拒絕，換新對話，提示詞要寫完整畫風。
- 主 session 檢查：畫風一致、沒有文字、沒有崩壞的手或臉、內容符合出處。
